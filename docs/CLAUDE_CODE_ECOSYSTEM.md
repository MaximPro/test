## 💻 Installation Beispiele

### SuperClaude installieren:
```bash
# Via NPM
npm install -g @superclaude-org/superclaude && superclaude install

# Via Python
pip install SuperClaude && SuperClaude install
```

### Plugin Marketplace hinzufügen:
```bash
/plugin marketplace add jeremylongshore/claude-code-plugins-plus
/plugin install <plugin-name>
```

### MCP Server konfigurieren:
```bash
/mcp  # Öffnet MCP Configuration
```

### Security Review:
```bash
/security-review  # Ad-hoc Security Analysis
```
