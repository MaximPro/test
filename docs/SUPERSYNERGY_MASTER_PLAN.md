### Integration with chat-man

The CRM system integrates seamlessly with chat-man's existing features:

1. **Chat Interface** → CRM actions
   - "Show me all leads from last week" → Query CRM
   - "Create a new contact for John Doe" → Add to CRM
   - "Schedule a follow-up with Sarah" → Create task

2. **RAG System** → CRM knowledge
   - Embed CRM data (contacts, deals, interactions)
   - Semantic search across customer data
   - AI answers questions about customers

3. **Security** → CRM data protection
   - All CRM data encrypted (AES-256-GCM)
   - DSGVO-compliant by default
   - Audit logging for all CRM actions

4. **Workflows** → CRM automation
   - Trigger workflows from CRM events
   - Update CRM from workflow results
   - End-to-end automation

### Database Schema

```sql
-- Extend existing chat-man schema with CRM tables

-- Contacts
CREATE TABLE crm_contacts (
  id TEXT PRIMARY KEY,
  email TEXT UNIQUE NOT NULL,
  first_name TEXT,
  last_name TEXT,
  company TEXT,
  phone TEXT,
  lead_score INTEGER DEFAULT 0,
  lifecycle_stage TEXT DEFAULT 'lead',

  -- DSGVO
  consent_marketing BOOLEAN DEFAULT 0,
  consent_profiling BOOLEAN DEFAULT 0,
  consent_timestamp TEXT,

  -- Metadata
  created_at TEXT NOT NULL,
  updated_at TEXT NOT NULL,
  deleted_at TEXT
);

-- Deals
CREATE TABLE crm_deals (
  id TEXT PRIMARY KEY,
  contact_id TEXT REFERENCES crm_contacts(id),
  title TEXT NOT NULL,
  value REAL,
  stage TEXT NOT NULL,
  probability INTEGER,
  close_date TEXT,
  created_at TEXT NOT NULL,
  updated_at TEXT NOT NULL
);

-- Interactions
CREATE TABLE crm_interactions (
  id TEXT PRIMARY KEY,
  contact_id TEXT REFERENCES crm_contacts(id),
  type TEXT NOT NULL, -- email, call, meeting, note
  content TEXT,
  metadata TEXT, -- JSON
  created_at TEXT NOT NULL
);

-- Workflows (n8n metadata)
CREATE TABLE crm_workflows (
  id TEXT PRIMARY KEY,
  name TEXT NOT NULL,
  description TEXT,
  category TEXT,
  trigger_type TEXT,
  n8n_workflow_id TEXT,
  enabled BOOLEAN DEFAULT 1,
  run_count INTEGER DEFAULT 0,
  last_run TEXT,
  created_at TEXT NOT NULL
);
```

## Deployment Strategy

### One-Click Installation

```bash
# Clone SuperSynergy
git clone https://github.com/your-org/supersynergy.git
cd supersynergy

# Run setup script
./setup.sh

# Start SuperSynergy
./start.sh
```

**Setup script does**:
1. Checks for Bun (installs if missing)
2. Checks for Ollama (installs if missing)
3. Downloads LLaMA2 model
4. Sets up databases (SQLite + PostgreSQL)
5. Seeds 100 workflows
6. Starts all services
7. Opens http://localhost:3010

**Total time**: 5-10 minutes

### Docker Deployment (Optional)

```yaml
version: '3.8'

services:
  supersynergy:
    image: supersynergy:latest
    ports:
      - "3010:3010"
    volumes:
      - ./data:/app/data
    environment:
      - NODE_ENV=production
      - DATABASE_URL=postgresql://...
```
