## 💡 Verwendungshinweise

### Installation von Plugins:
```bash
# Plugin Marketplace hinzufügen
/plugin marketplace add user-or-org/repo-name

# Plugin installieren
/plugin install plugin-name

# Interaktiver Modus
npm run create-repo:interactive
```

### MCP Server Configuration:
```bash
# MCP Konfiguration öffnen
/mcp

# Im VS Code Extension
# Konfiguration in ~/.config/claude/claude_desktop_config.json
```

### Security Review:
```bash
# Ad-hoc Security Analyse
/security-review

# GitHub Action Integration verfügbar
```

## 🎯 Best Practices

1. **Ein Job pro Subagent:** Jeder Subagent sollte eine klare, einzelne Aufgabe haben
2. **Orchestrator verwenden:** Für komplexe Workflows einen Orchestrator nutzen
3. **Plugins bevorzugen:** Nutze Plugins statt einzelner MCP Server für bessere Organisation
4. **Security First:** Nutze Security Review Tools vor jedem Commit
5. **Dokumentation:** Automatische Dokumentation mit Claude Code generieren
6. **Testing:** TDD-Ansatz mit Claude Code für bessere Code-Qualität
